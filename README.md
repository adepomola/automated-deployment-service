# Automated Deployment Service

## Overview

A DevOps deployment solution designed to simplify the deployment and
maintenance of web applications for small businesses and developers.

## Project Goal

The goal is to provide a reusable deployment workflow using AWS,
Terraform, Docker, Nginx and GitHub Actions.

## Planned Features

- AWS infrastructure provisioning with Terraform
- Dockerized application deployment
- CI/CD with GitHub Actions
- Nginx reverse proxy
- HTTPS/SSL
- Basic monitoring
- Automated deployment

## Technology Stack

- AWS
- Terraform
- Docker
- GitHub Actions
- Nginx
- Linux
